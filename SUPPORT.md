# Support

## Bugs

Use the GitHub bug-report form for reproducible problems in a supported
WordPress, WooCommerce, and PHP environment. Include sanitized logs, exact
versions, reproduction steps, and whether HPOS is enabled.

## Feature proposals

Use the feature-request form. Describe the user problem, desired outcome, and
why existing WooCommerce or PromoGuard behavior does not address it.

## Security issues

Follow [SECURITY.md](SECURITY.md). Do not disclose vulnerabilities in public
issues or discussions.

## Usage questions

Consult the [administration guide](promoguard-for-woocommerce/docs/ADMINISTRATION.md),
[testing guide](promoguard-for-woocommerce/docs/TESTING.md), and other documents
linked from the root [README.md](README.md) before opening an issue.

Community support is provided on a best-effort basis. The repository does not
currently offer a guaranteed response time or private implementation support.
