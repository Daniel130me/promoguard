Campaign-level eligibility controls for native WooCommerce coupons.

== Description ==

PromoGuard groups related WooCommerce coupons into campaigns and applies shared
customer eligibility rules. The plugin is currently under private-beta
development and is not ready for production use.

== Installation ==

This development version should only be installed in an isolated test site.
